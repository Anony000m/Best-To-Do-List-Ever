# Small Wins

A minimalist, local-first to-do list with reminders, XP, and small celebrations.

## Privacy

Small Wins does not use an account, analytics, an AI service, or a task database in the cloud. Task content, reminder times, completion history, and XP are stored in the browser on the device where you use the app.

The website host necessarily serves the app files when you visit the site, but the app does not send your task contents back to the host.

## Install on iPhone

Open the GitHub Pages site in Safari, tap **Share**, then **Add to Home Screen**.

The web version works offline after its assets have been cached. Reminder times are local; while the web app is fully closed, iOS does not provide purely local scheduled background notifications to a PWA.
